# Orient me

1. Confirm the current directory and Git root.
2. Read `AGENTS.md`, the README and contribution guidance that apply here.
3. Identify the repository's purpose, language, entry points and documented
   setup, build and test commands.
4. Trace only the smallest path relevant to the participant's outcome.
5. Report a short map: where we are, what matters, what is uncertain and the
   safest next step.

Do not edit files during orientation unless the participant explicitly asks.
Do not guess missing commands, credentials or private dependencies.
