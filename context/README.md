# Public project maps

The catalogue in `fieldkit.json` is the public allow-list. Begin with the
checked-out project's own README and instructions; those are its source of
truth.

- **Bundle Spec:** learn the data contract before inventing a new Speckle data
  representation.
- **Python SDK:** use for Python scripts, notebooks and Python Automate work.
- **.NET SDK:** use for .NET applications, integrations and .NET Automate work.
- **Automate starters:** begin with the language you can run and understand;
  keep the first function small and observable.
- **Docs:** use when the outcome is explanation, onboarding or a public guide.
- **.NET host connectors:** use `speckle-sharp-connectors` for host integration
  logic and `speckle-connectors-dui` for the shared connector interface.
- **Standalone connectors:** use the dedicated Archicad, SketchUp, Power BI or
  Blender repository when the work belongs specifically to that application.

These maps intentionally contain no internal repository names, endpoints,
credentials or private architecture.

For an evidenced model-data question, use
[`ask-speckle`](../.agents/skills/ask-speckle/SKILL.md). It explains when to use these
sources together and when to stop rather than force a property query to answer
a relationship, geometry or practice question.
