# Personal skills and context

This directory is a private staging area. Everything beside this README is
ignored by Git.

Use it for a skill, glossary or note that is useful to you but inappropriate
for the shared FieldKit—for example, a personal review checklist. Do not put
credentials, tokens, customer information or restricted model files here.

Clients do not all discover personal skills from the same place. Files here
only influence an agent when you explicitly reference them, unless you copy or
link them into a location supported by that client. See
[`docs/client-setup.md`](../docs/client-setup.md).
