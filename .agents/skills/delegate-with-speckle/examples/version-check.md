# DELEGATE example: check every new version

Task: when a new model version arrives, run a defined check and publish a
result without modifying the model.

Specify the trigger, exact required properties, output statuses, known-answer
fixtures, permissions, duplicate-event behaviour and owner for failures. Use
the smallest matching Automate starter. Keep the calculation separate from
the event wrapper and stop before deployment or project attachment unless the
user explicitly authorizes the named target.
