# ASK example: connector capability

Question: does the current Revit connector preserve a particular parameter on
send and recreate it on receive?

Record the Revit and connector versions and treat send and receive as separate
claims. Inspect docs, the owning conversion path and relevant tests. Return a
confidence for each direction and name the smallest round-trip that would
resolve any remaining runtime uncertainty. No connector change is required to
complete this ASK.
