# Analysis terminology and semantic checks

Names are clues, not definitions.

- **Property path:** the actual location of a value in the version dataset.
- **Display value:** a producer-formatted value; preserve it alongside any
  numeric normalisation.
- **Bundle dataset:** the portable, table-and-graph representation described by
  the checked-out Bundle specification.
- **Legacy dataset:** the earlier packfile plus EAV property representation.
- **SDK route:** object transport or application code used when dataset queries
  cannot provide the required objects, relationships or geometry.
- **Connector semantics:** how a host application object and its parameters are
  converted into Speckle data.
- **Clear width:** a domain measurement whose reference faces, obstructions,
  height, tolerance and minimum-along-route meaning must be stated. It is not
  synonymous with any property merely named `Width`.
- **Expected utilisation:** a project/domain classification. Do not infer it
  from room names or occupancy unless an applicable practice defines that
  mapping.

For consequential measurements, record who owns the definition and which
project, contract or regulatory source gives it authority.
