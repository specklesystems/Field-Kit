# BUILD example: corridor evidence table

Outcome: create a repeatable, read-only analysis that reports corridor widths
against a threshold supplied by the participant.

Use the safe analysis scaffold. Record exact model/version inputs, discovered
classification/property paths, units and the supplied threshold. Test known
pass, fail, missing and ambiguous cases. If clear width requires geometry or
an undefined measurement convention, stop and expose that boundary rather
than substituting a nominal `Width` property.
